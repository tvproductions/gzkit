## Decisions Made

- **Decision:** GHI #679 routed as a direct fix, not an OBPI.
  **Rationale:** GHI-tracked defect repair routes to direct fix by operator
  doctrine regardless of surface heat; precedent ≥5 recent `fix(` commits.
  **Alternatives rejected:** OBPI ceremony (inverts defect-fix routing — the
  doctrine alarm).

- **Decision:** #679 fixed with `try/finally` + `booked` flag, not `try/except
  Exception`.
  **Rationale:** the pythonic rule forbids bare `except Exception` outside CLI
  boundaries; `finally` books the aborted terminal event without swallowing the
  exception (it re-propagates via `sys.exc_info()[1]`). quality-reviewer
  independently confirmed this is failure-atomic, not failure-hiding, and that
  `airlock_enter` correctly needs NO equivalent guard (it books last — nothing to
  pair on failure).
  **Alternatives rejected:** bare `except`; a separate `airlock_aborted` event
  type (breaks mechanical pairing with `airlock_in`).

- **Decision:** closed ZERO GitHub issues during closeout; left #679 open (then
  fixed+closed on operator request).
  **Rationale:** dead-letter doctrine — #679 was a real unfixed defect at closeout
  time; closing it "as resolved by closeout" would have been a dead-letter.
  **Alternatives rejected:** sweeping #679 closed because "it's about the airlock."

- **Decision:** updated ADR-0.33.0 frontmatter `status:` to `Validated`.
  **Rationale:** prior validated ADRs (0.31.0, 0.32.0) carry `status: Validated`
