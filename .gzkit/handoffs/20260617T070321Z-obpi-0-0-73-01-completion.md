## Important Context

- **Registry derivation is the load-bearing invariant.** `build_qc_registry()`
  must NEVER become a hand-maintained list. It derives membership from
  `_build_check_steps()`; the `KeyError` sentinel enforces this mechanically.
  When OBPI-02 (`gz validate --qc-binding`) adds negative-control runs, it will
  populate the currently-empty `theater_flags` field — do not populate it in
  OBPI-01 scope.
- **All 32 current steps are classified `bound`.** OBPI-02 will behaviorally
  re-test each via negative-control fixtures; some (e.g. Behave on empty input)
  may reclassify to `advisory`/`unenforced` then. That is OBPI-02 work, not a
  defect in OBPI-01's classification.
- **Two gate-friction adjustments made this session** (brief adjusted to reality,
  not code contorted): (a) `req_atomic:` declared in brief frontmatter — the
  whole module is one indivisible authoring unit, no REQ subdivides into
  separately-attributable labor; (b) `src/gzkit/traceability.py` added to the
  allowlist as the `@covers` decorator import (read-only test infra) — sibling
  precedent: OBPI-0.0.17-01 declares it identically.
- **`@covers` must be decorator form, not comment form.** The REQ-coverage gate
  in `gz obpi complete` RUNS each covering test by building a `module.Class.method`
  unittest target from the AST scanner's `qualified_name`. Comment-form
  `# @covers` records the file path as the identifier, producing an invalid
  target → "failing-cover". Decorator form `@covers("REQ-...")` resolves correctly.

## Decisions Made

- **Decision:** Declare `req_atomic:` for all five REQs rather than mint
  `seq=02+` TASKs.
  **Rationale:** The QCStep model, its derivation, and its classification ship as
  one `src/gzkit/qc_binding.py` write with one covering test module — genuinely
  indivisible labor (GHI #590 doctrine: make the call where the labor happens).
  **Alternatives rejected:** Artificial TASK subdivision — would fabricate labor
  units that did not exist.

- **Decision:** Classify all 32 steps `bound` in OBPI-01.
  **Rationale:** Every `gz check` step exits non-zero on violation today; the
  honest classification at this stage is `bound`. Behavioral re-test belongs to
  OBPI-02's negative-control scope.
  **Alternatives rejected:** Pre-emptively marking some `advisory` — would be a
  guess ahead of OBPI-02's negative-control evidence.

- **Decision:** Add `src/gzkit/traceability.py` to the allowlist.
  **Rationale:** The reconcile engine flagged it (same `src/gzkit/` neighborhood
  as `qc_binding.py`); it is the `@covers` decorator import, read-only test infra.
  Sibling precedent OBPI-0.0.17-01 declares it identically.
  **Alternatives rejected:** Reverting to comment-form `@covers` to avoid the
  import — would re-break the REQ-coverage gate.
