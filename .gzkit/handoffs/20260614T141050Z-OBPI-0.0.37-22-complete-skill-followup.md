## Decisions Made

- **Decision:** Amend the brief allowlist to add `src/gzkit/quality.py` rather
  than relocate the runner function into the allowlisted `commands/quality.py`.
  **Rationale:** All 22 sibling `run_*_audit` runners live in `gzkit.quality`;
  relocating would break convention. The brief was stale/under-declared, not the
  code. Confirmed by a dispatched evaluator agent.
  **Alternatives rejected:** (a) relocate function to fit stale allowlist —
  rejected as code-contortion; (b) declare `sensitivity: security` — rejected as
  unwarranted and divergent from sibling precedent.
- **Decision:** Release the lock via a handoff register entry (this document)
  rather than `--abandon`.
  **Rationale:** The OBPI is complete, not abandoned. `--abandon` is semantically
  wrong. ADR-0.0.37 has remaining OBPIs, so a handoff is genuinely warranted.
  **Alternatives rejected:** `--abandon` (wrong semantics); `--force` (only
  bypasses ownership, not the register-entry gate).
