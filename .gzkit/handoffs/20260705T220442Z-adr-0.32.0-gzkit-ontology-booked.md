- **Decision:** HULL is one unified heavy feature ADR, not a constellation.
  **Rationale:** GO-attested singular shape plus the unification thesis; OBPI
  decomposition manages blast radius (KEEL/ADR-0.31.0 proved a heavy 3-OBPI ADR
  lands). **Alternatives rejected:** 3-ADR constellation (invents cross-ADR
  coherence machinery — reverted this session).
- **Decision:** substrate is `tree-sitter + networkx + Pydantic`.
  **Rationale:** GO-attested; graph algorithms and polyglot parse are stdlib
  cannot-do. **Alternatives rejected:** stdlib `graphlib`/`ast` (topo-sort only,
  cannot image lateral traversal — reverted this session).
- **Decision:** unify — `triangle.py` and `get_artifact_graph` absorbed as views
  over one graph. **Rationale:** separation invites drift; one type system
  distinguishes edges by endpoint object-types. **Alternatives rejected:** a
  parallel typed model; widening `triangle.py`'s `EdgeType`.
- **Decision:** corpus-first MVP (model + corpus projection + `gz ontology`
  interface + doctrine/Boundary-Invariants). **Rationale:** highest-value first
  cut (the governance-lineage sonar); defers the one-way L2 door.
  **Alternatives rejected:** building all three domains at once.
- **Decision:** OKF open-absorption (Doc subtype = OKF type verbatim, no
  subset-validator). **Rationale:** honors OKF BI-1/BI-3. **Alternatives
  rejected:** a subset-validator constraining Doc subtype to a closed set.
