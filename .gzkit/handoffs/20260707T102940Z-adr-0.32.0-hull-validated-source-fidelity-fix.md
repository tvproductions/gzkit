## Decisions Made

- **Decision:** Route the source-fidelity gap as a GHI-tracked direct fix, not
  an OBPI.
  **Rationale:** Operator explicitly directed "file a GHI to track and direct
  fix now"; operator doctrine holds a GHI-tracked defect repair routes to direct
  fix regardless of the OBPI-ceremony criteria (the GHI is the work order and
  receipt).
  **Alternatives rejected:** OBPI ceremony (the port-method change is a runtime
  contract touch that would normally trigger it) — overridden by operator
  direction.

- **Decision:** Fix the source domain only; leave OKF's `complete=present`
  unchanged.
  **Rationale:** tree-sitter `.parse()` never raises (silent partial parse is a
  real lie); `absorb_okf_bundle` is all-or-raise (no silent partial path — so
  presence is honest completeness).
  **Alternatives rejected:** a symmetric OKF completeness metric — would be an
  always-true metric (theater the audit exists to kill).

- **Decision:** Add a domain-typed `parse_failures(files) -> tuple[str, ...]`
  port method rather than leaking `has_error`/`SyntaxError` across the seam.
  **Rationale:** Hexagonal rule 3 — no parser-native node crosses the port; each
  adapter answers in its own idiom (`ast` SyntaxError / tree-sitter `has_error`)
  and the core stays parser-ignorant. Makes it a class-fix: any future adapter
  must confess failures too.
  **Alternatives rejected:** reaching `root_node.has_error` from the core
  (leaks tree-sitter inward, violates rule 6 testability).

- **Decision:** Treat the campaign checkbox update as a living-checkoff, not an
  operator-ratified amendment.
  **Rationale:** The campaign states "Living: items check off with command
  evidence." Checking Phase 2 + advancing the Topmost pointer records completion;
  it changes no sequencing, scope, or §8 gate — so no § Amendments entry is
  needed (amendments are for substantive resequencing/scope changes).
  **Alternatives rejected:** an Archive amendment block (would be inline
  accretion the campaign warns against, for a non-amendment).
