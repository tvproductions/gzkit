## Important Context

- **`@enforces` is used on the production entrypoint in source, not on the test** —
  same call-site convention as `@covers`/`@advances`. The runner that invokes
  `entrypoint(fixture())` is OBPI-0.0.74-16, explicitly DENIED to this OBPI.
- **BI#7 seam-pin (forcing impossible by construction):** the registry stores the
  ORIGINAL `entrypoint` and `fixture` callables by identity — no `functools.partial`,
  no `lambda` pre-binding a forcing kwarg at the registration site. Tests assert
  identity (`record.entrypoint is _entrypoint`) and `assertNotIsInstance(...,
  functools.partial)`.

  `allowlist=1` — `src/gzkit/traceability.py` reported `missing_in_brief` solely

  the SUT `enforcement.py` (the neighborhood-filter false-positive class its own

  `src/gzkit/` level). Precedent: sibling OBPI-0.0.64-02 (`src/gzkit/tasks.py`
  `@advances`) did NOT list `traceability.py` despite the same import. Resolved via
  `gz obpi complete --accept-stale-reconciliation --reason '<precedent>'` — NOT by
  polluting the allowlist with an unmodified dependency.

## Decisions Made

- **Decision:** Source known-claims from `_PRODUCTION_NEGATIVE_CONTROLS.keys()` in
  `_qc_negative_controls`, lazy-loaded.
  **Rationale:** It is the existing authoritative claim-id set; no new data file, no
  new dependency (STDLIB-first / generalize-in-place per BI#6).
  **Alternatives rejected:** (1) format-only validation — the brief requires "unknown
  claim" to fail, needing an external known-set; (2) a new claims data file —
  duplicates an existing source.
- **Decision:** Resolve the reconcile `allowlist=1` drift via documented
  `--accept-stale-reconciliation` override, not by adding `traceability.py` to the
  allowlist.
  **Rationale:** `traceability.py` is unmodified cross-cutting test infra; adding it
  misrepresents scope. Convention (OBPI-0.0.64-02) forbids it. Gate Friction loop:
  evaluator determination → precedent evidence → documented override.
  **Alternatives rejected:** adding `traceability.py` to allowlist (scope
  misrepresentation); contorting code to a different module home (the gate-friction
  anti-pattern).
- **Decision:** `EnforcementClaimRecord` uses `arbitrary_types_allowed=True`.
  **Rationale:** callable fields (`fixture`, `entrypoint`) are not natively
  serializable Pydantic types. **Alternatives rejected:** storing qualified-name
  strings only — the runner (OBPI-16) needs the live callables.
