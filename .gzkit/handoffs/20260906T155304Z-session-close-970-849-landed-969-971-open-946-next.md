=== MEASURE SHELL SEMANTICS, DO NOT REASON ABOUT THEM ===

Two assumptions were wrong this session and both were caught only by running `sh -c`:

  set -e; false || echo caught        -> exit 0   (errexit suppressed left of `||`)

The errexit escape had been honoured for `||` and `&`, where the shell aborts nothing. It is now scoped to `;` and newline.
