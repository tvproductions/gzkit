## Important Context

- **OKF is orientation, never authority** (parent ADR Boundary Invariant 1). Nothing
  in the bundle may be consumed as enforcement evidence by any `gz validate` / gates /
  closeout surface. The generator imports only `pathlib`, `yaml`, and the OBPI-01
  `ConceptFrontmatter` model — no enforcement wiring; the fence holds.
- **Module entry point is `python -m gzkit.knowledge`** (via `src/gzkit/knowledge/__main__.py`),
  NOT `python -m gzkit.knowledge.generate`. The quality review caught a `RuntimeWarning`
  on the latter (package `__init__` eagerly imports the submodule); the `__main__.py`
  form is warning-free by construction. The brief Demo/Key-Proof were amended to match.
- **Idempotency is load-bearing**: output carries no timestamp/random/`datetime.now()`;
  slugs emitted in `sorted` order; YAML dumped `sort_keys=True`. Do not introduce
  non-determinism into the output.
- **Plan-audit id-form trap (process note)**: `gz plan audit` keys the receipt by the
  id you pass it. The `pipeline-gate.py` hook derives marker lookup from the receipt's
  `obpi_id` and matches the markers (full slug). Passing the SHORT id to plan-audit
  produces a receipt that won't match the full-slug markers → blocked writes. Always
  pass the **full OBPI slug** to `gz plan audit` (matching the brief frontmatter `id`).
- **`req_atomic` declared**: all 4 REQs are satisfied by the single `generate_bundle`
  function (no sub-REQ labor); the brief frontmatter carries the exemption with rationale.

## Decisions Made

- **Decision:** Apply quality-review option (b) — relocate the module entry to
  `src/gzkit/knowledge/__main__.py` and run `python -m gzkit.knowledge`.
  **Rationale:** Shipping `this may result in unpredictable behaviour` on a documented
  Heavy-lane operator demo command is a trust defect (a correction, not enhancement);
  the package-as-command form is the idiomatic warning-free fix.
  **Alternatives rejected:** (a) leave the warning — ships a wart on a documented surface;
  (c) PEP-562 lazy `__getattr__` in `__init__` — cleverness over clarity to preserve a
  non-load-bearing command string.
- **Decision:** Declare `req_atomic:` for all four REQs rather than subdividing TASKs.
  **Rationale:** The generator is one cohesive function; there is genuinely no labor
  below the REQ level, so seq=01-per-REQ is the true labor shape (mirrors OBPI-01).
  **Alternatives rejected:** `gz task start --seq next` subdivision — would fabricate
  labor units that did not exist.
- **Decision:** Resolve the pipeline-gate block by re-running `gz plan audit` with the
  full slug (governed CLI path), not by hand-editing the marker.
  **Rationale:** AGENTS.md Never #6 forbids working around hook blocks; the real defect
  was an id-form mismatch in the receipt, fixed at its source.
  **Alternatives rejected:** hand-editing the pipeline marker / receipt to satisfy the hook.
