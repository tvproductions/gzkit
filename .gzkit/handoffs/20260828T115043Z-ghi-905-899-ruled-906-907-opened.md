## Important Context

`gz validate --distribution` is STATIC BY DOCTRINE, not by regression. `audit_distribution` opens with "no wheel build required" and walks pyproject include globs against the SOURCE tree. `docs/governance/trust-doctrine.md:88` requires exactly that of it: a T0 audit MUST detect missing package data without depending on downstream installation evidence. Reading `dist/` would breach the doctrine the audit implements. Never re-derive this as a defect.

T0's wheel-reading arm is `tests/test_packaging.py`, inside the **Test** step. It builds its own wheel with `uv build --wheel --out-dir <tmpdir>`, commented "to keep build hermetic and avoid polluting the repo's dist/", then opens it with `zipfile`. So `dist/` is written by Behave and read by nothing in the gate.

Behave's scenarios are ALREADY isolated. `features/environment.py:90` gives every scenario a fresh `mkdtemp` and `chdir`s into it; there is no `before_all` and no `before_feature`. That single fact decides the sharding mechanism: `os.chdir` is process-global, so scenarios can never be threaded inside one interpreter, and can always be split across processes. 68 feature files, 443 scenarios, zero `Scenario Outline`s, no feature-level tags — nothing splits a file and no tag inheritance crosses a shard boundary.

Sharding is NOT the tag-filter proposal already ruled on. `src/gzkit/quality.py:441-457` records the 2026-08-26 operator ruling that the gate runs unfiltered on purpose: 117 of 443 scenarios carry no effective `@REQ-` tag, so a filter would drop a quarter of the suite silently. Sharding changes only which process a scenario runs in; every scenario still runs. Scenario conservation is the primary test any implementation must carry.

Any authorship witness has a design problem underneath it: a checked-in denylist cannot name the token it forbids without being the leak. The tractable shape is a runtime `git config user.name` read, mirroring the existing `--authorship` arm's `git config user.email` read — which inherits the per-clone weakness GHI #725 already named.

A witness must not fire on third-party names. `docs/governance/research_sources/` carries 18 lines matching the same literal; they are author lists of cited arXiv papers. A blind literal sweep would rewrite published bibliographies. It must also match more than one spelling — four in the repairable tier, six in the ledger.

The `verifier-pipe-gate` PreToolUse hook fired three times this session and was correct each time. It parses only the FIRST statement of a compound command, so a `set -o pipefail` placed after a heredoc does not register — split the heredoc and the piped verifier into separate calls.

`git grep -c` on a file with zero matches prints nothing and exits 1. A `|| echo 0` fallback around it reads as a measurement when it is an error path. Prefer a direct `grep -c` across the file list when the count is the finding.
