## Important Context

Five constraints shaped this session, and the first is why the fix was not a test edit.

FIRST, the failing test was the messenger, not the defect. The real consumers of list_handoffs take element [0] as an ANSWER: _newest_predecessor builds the continues_from lineage link from it, and handoff_resume_gate.newest_handoff uses it to name which handoff an operator must authorize, which is the very hook that gated this session's first three commands. Two handoffs written in the same second are reachable in production, because gz obpi complete writes a mechanical completion register entry (token-block Sub-Invariant 6) that can land alongside an authored one. A non-total sort therefore makes governance lineage and the resume gate platform-dependent, not merely flaky.

SECOND, observing a genuine RED locally took deliberate fixture choice. Python's sort is stable, so equal keys preserve glob order, and APFS returns a hash order that is stable per name-set. Most fixture pairs happen to agree with the intended tie-break and would have gone GREEN without the fix. Probing seven candidate name pairs found that alpha/beta disagrees on APFS, which is why the regression test uses those slugs. A test that can fail only on CI is not a RED observation.

THIRD, the tie-break carries no recency meaning and the code says so. Within one timestamp-second there is no semantically newer handoff; the path is used because it makes the order total. Documenting it as a recency signal would assert a fact the data does not carry.

FOURTH, the original failing test was itself leaning on the tie-break. It seeded both handoffs at an identical timestamp and passed only because "second" sorts above "first"; renaming a slug would have broken it for reasons unrelated to its purpose. Its predecessor now carries a strictly earlier timestamp, so it asserts the chronological carry-forward it is named for.

FIFTH, triage is read-only and its rank schema is structural-only by design. The agent contributes selection, ordering, and severity; the renderer owns all prose, because earlier versions accepted agent prose that then duplicated the rendered deliverable in the operator's chat surface. Blocker-freshness flags are citations, not verdicts: a blocker may name a closed GHI as a precondition (gate lifted) or as provenance (still stands), and nothing mechanical separates them, so each of the five flagged items was read and adjudicated individually.
