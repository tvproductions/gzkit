# `.claude/rules` context audit (read-only), 2026-11-08

Scope: all 27 files in `.claude/rules/`, 155,521 B. Each file was read in full, along with root `AGENTS.md`. Where a rule points at a doc, the doc's headings were read, and for `hexagonal-architecture.md` its relevant sections as well. A script searched every rule for sentences that appear verbatim in `AGENTS.md`, in `docs/**/*.md` and in the other rules.

Method: the byte count for each section is measured, splitting the files at `#`/`##`/`###` headings. Splitting a section across categories a–e is my reading of the paragraphs, so those splits are accurate to about ±100 B per row. Every row sums to the file's exact byte count. Rule-version banners and dated rulings are counted under (b). Frontmatter and the title are counted under (a).

Categories: **a** = a binding instruction the agent needs at edit time. **b** = rationale, history or pedagogy. **c** = a procedure that belongs in a skill. **d** = duplicated elsewhere (target named). **e** = already enforced mechanically (witness named). Every `gz validate --<scope>` named below is a registered scope (checked against `uv run gz validate --help`).

## Canon vs mirror

- All 27 mirrors differ from `.gzkit/rules/` only in the expected ways: the frontmatter `id:` and `description:` are stripped, and the `<!-- Generated by gz agent sync -->` line is added (diffed for models, tests and pythonic; every file reports DIFF of that shape). No content drift was found.
- The two canon files that are not mirrored:
  1. `.gzkit/rules/complexity-thresholds.json` is the threshold data file. It is a JSON sibling read by `load_threshold_table`, not a rule.
  2. `.gzkit/rules/AGENTS.md` is a **generated** Codex subtree file, written by `sync_nested_agents_md` (`src/gzkit/rules/__init__.py:~600`). It concatenates the rules whose globs cover `.gzkit/rules/**`: agent-failure-modes, mode-contract and skill-surface-sync. It is generated output placed inside a canonical directory. Claude does not load nested AGENTS.md (GHI #1021 removed the CLAUDE.md importers), so it costs Claude nothing.

## Defects found

1. **agents-md-map-doctrine glob targets generated surfaces.** It matches `AGENTS.md`, `CLAUDE.md` and `.claude/rules/*.md`. The canon is `.gzkit/corpus/AGENTS.md.jsonl` and `.gzkit/rules/*.md`, so the rule never loads where canon is edited.
2. **model-selection glob** names the `.claude/agents/**` mirror. The canon `.gzkit/agents/**`, which the rule's own `--model-class-only` sentence names, is not in the glob.
3. **hexagonal-architecture § Verify cites `gz lint` / `gz typecheck`**, and neither checks import purity. The real witness is `tests/policy/test_import_boundaries.py::CorePurityIsAnAllowlist` (advisory-rules-audit row 64), and the rule never names it.
4. **models.md does not cite `gz validate --pydantic-models`**, which enforces its Do Not/Verify lists (`trust_audits/models.py`).
5. **pythonic.md has a broken sentence:** "`complexity_advise.py` is reads `lizard_ccn` alone".
6. **pythonic.md § Size Limits** records a live three-way threshold conflict "routed for operator decision" with no GHI. That makes it untrackable under PRIME DIRECTIVE 6. Note that I checked only the rule text for a GHI.
7. **security-sensitivity § Registry contract** describes an enforcement gap (a briefless edit to `security_surfaces.json` is never inspected) and its candidate fix, with no GHI. Same trackability defect.
8. **complexity-doctrine's canonical-string example** cites `distilled-characteristics-2026-05-04.md § radon-cc`. Radon retired in GHI #1183 (complexity-thresholds 0.6.0), so the example is stale.
9. **gh-cli, task-discovery and mx-mode use the wrong delivery channel.** They bind at Bash time, commit time or session time, but path-scoped rules load only on file Read/Write/Edit. The real carriers are hooks (prepare-commit-msg, mx-awareness) or skills.
10. **model-selection's frontmatter example comment** lists `haiku, sonnet, opus` while the valid values include `fable`. I found no witness for "every skill declares `model:`" in `skills_audit.py`, although all 74 skills currently comply.
