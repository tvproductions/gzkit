# Competitor Radar Grill Questions

Use one question at a time. Give a recommended answer before asking the
operator to confirm, amend, or reject it.

## Per Suggested Move

1. Are we copying a product or absorbing a mechanism?
2. What evidence proves the strength or trajectory changed?
3. Are we chasing fashion?
4. Is this foundation intent, feature capability, pool backlog, GHI, or reject?
5. Which gzkit invariant must not weaken?
6. What mechanical witness would make this safe?
7. What route do you recommend?

## Admission For New Competitors

1. What concrete evidence shows this belongs in the registry?
2. Which strength pattern does it represent?
3. Which existing comparator does it displace, refine, or contradict?
4. Does it create a new gzkit opportunity or only reinforce an existing one?
