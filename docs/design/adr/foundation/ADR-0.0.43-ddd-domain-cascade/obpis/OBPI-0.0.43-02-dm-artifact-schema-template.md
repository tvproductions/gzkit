# OBPI-0.0.43-02-dm-artifact-schema-template: DM tactical artifact + schema + template

## ADR Item

- **Source ADR:** `docs/design/adr/foundation/ADR-0.0.43-ddd-domain-cascade/ADR-0.0.43-ddd-domain-cascade.md`
- **Checklist Item:** #2 — "DM artifact + schema + template — New artifact type at `docs/design/domain/DM-<bc-slug>.md`; `DomainModel` Pydantic model with `Aggregate` / `Entity` / `ValueObject` / `DomainEvent` / `ImplementationSurface` / `InboundContract` / `OutboundContract`; `src/gzkit/schemas/domain_model.json`; template file; Aggregates + Implementation Surface required, rest optional."

**Status:** Draft

## Objective

Introduce a new tactical-DDD artifact type `docs/design/domain/DM-<bc-slug>.md` — one per bounded context — with the full Evans tactical vocabulary backed by Pydantic models and JSON Schema. Aggregates and Implementation Surface are required; Entities, Value Objects, Domain Events, and Open Questions are optional. The Implementation Surface declaration is the load-bearing input for OBPI-11's AST cross-context import enforcer.

## Lane

**Heavy** — introduces a new artifact type (DM) with a new canonical directory contract (`docs/design/domain/`), new Pydantic models in the public governance surface, a new JSON Schema, and a new template file.

## Requirements (FAIL-CLOSED)

1. **REQUIREMENT (`DomainModel` root).** Pydantic class with `bc_slug: str` (matches `^[a-z][a-z0-9-]*$`), `parent_prd: str`, `owner_persona: str`, `lifecycle_state: Literal["active", "deprecated", "retired"]`, `glossary_specializations: list[UbiquitousLanguageTerm]`, `aggregates: list[Aggregate]` (≥1), `entities: list[Entity] = []`, `value_objects: list[ValueObject] = []`, `domain_events: list[DomainEvent] = []`, `implementation_surface: ImplementationSurface` (required), `inbound_contracts: list[InboundContract] = []`, `outbound_contracts: list[OutboundContract] = []`, `open_questions: list[str] = []`, `decision_history: list[str] = []` (auto-populated, Layer-3-within-Layer-1). `extra="forbid"`.
2. **REQUIREMENT (`Aggregate`).** Pydantic class with `name: str` (PascalCase), `root_entity: str`, `invariants: list[str]` (≥1), `transactional_boundary: str` (one-sentence). `extra="forbid"`.
3. **REQUIREMENT (`ImplementationSurface`).** Pydantic class with `paths: list[str]` (Python module paths or globs), `notes: str = ""`. Empty `paths` valid (signals "no code surface yet"). OBPI-11's AST enforcer reads from `paths`.
4. **REQUIREMENT (`InboundContract` / `OutboundContract`).** Pydantic class with `other_bc: str`, `relationship_type: RelationType`, `description: str` (≥10 words), `pinned_terms: list[str] = []`. `extra="forbid"`. MUST be reflected in PRD § 2.3 (OBPI-06 enforces consistency).
5. **REQUIREMENT (`Entity` / `ValueObject` / `DomainEvent`).** Each Pydantic class with `name: str`, `fields: dict[str, str]`, `notes: str = ""`. Optional in `DomainModel`. `extra="forbid"`.
6. **REQUIREMENT (DM template).** `src/gzkit/templates/dm.md` scaffolds: frontmatter, required sections (`## Identity`, `## Glossary Specializations`, `## Aggregates`, `## Implementation Surface`, `## Inbound Contracts`, `## Outbound Contracts`), optional sections commented out (`<!-- ## Entities -->`, `<!-- ## Value Objects -->`, `<!-- ## Domain Events -->`, `<!-- ## Open Questions -->`), and `## Decision History` with `<!-- AUTO-GENERATED by gz domain regenerate; DO NOT EDIT -->` marker.
7. **REQUIREMENT (JSON Schema).** `src/gzkit/schemas/domain_model.json` validates full `DomainModel` with `"additionalProperties": false` throughout.
8. **REQUIREMENT (directory contract).** `docs/design/domain/.gitkeep` exists; directory is precondition for every downstream OBPI consuming DMs.
9. **REQUIREMENT (no downstream coupling).** Nothing here may presuppose CLI (OBPI-03), validator (OBPI-06), or AST enforcer (OBPI-11). DM schema/template MUST be parseable standalone.

> STOP-on-BLOCKERS: if `RelationType` cannot be imported cleanly from `domain_models.py` (circular-import risk between `Aggregate` and `InboundContract`), halt and surface; never duplicate the enum.
