# OBPI-0.0.36-05-skill-prose-sweep-self-close: Skill Prose Sweep — Self-Close

## ADR Item

- **Source ADR:** `docs/design/adr/foundation/ADR-0.0.36-universal-obpi-attestation/ADR-0.0.36-universal-obpi-attestation.md`
- **Checklist Item:** #5 — "Skill prose sweep across `gz-obpi-pipeline`, `gz-obpi-reconcile`, `ghi-close`, `gz-adr-closeout-ceremony` plus rules grep + sync to vendor mirrors"

**Status:** Draft

## Objective

Sweep every skill body and rule file under `.gzkit/skills/**/SKILL.md`, `.gzkit/rules/**/*.md`, and the canonical CLAUDE/AGENTS rule mirrors for any reference to the deleted lite-lane self-close path, replace with universal-attestation language consistent with ADR-0.0.36, bump skill+rule version markers per `.gzkit/rules/skill-surface-sync.md`, then run `uv run gz agent sync control-surfaces` to propagate to all vendor mirrors and verify mirror parity.

## Lane

**Heavy** — touches the agent control surface (skills + rules) on which every agent's per-turn contract depends. Drift between canon and mirrors after this sweep would re-introduce the GHI #332 doctrine smell through whichever surface an agent reads next. Mirror propagation is itself a fail-closed gate — partial sync is a Heavy-lane Gate 3 failure.

## Allowed Paths

- `.gzkit/skills/gz-obpi-pipeline/SKILL.md` — primary pipeline skill referencing OBPI completion attestation
- `.gzkit/skills/gz-obpi-reconcile/SKILL.md` — reconciliation skill referencing brief-status attestation
- `.gzkit/skills/ghi-close/SKILL.md` — already updated this ADR's authoring session to v2.3.0; sweep confirms no remaining self-close references and that the universal-attestation reference is consistent
- `.gzkit/skills/gz-adr-closeout-ceremony/SKILL.md` — closeout-ceremony skill referencing lane-conditional attestation
- `.gzkit/skills/**/SKILL.md` — any other skill under canon discovered by grep to reference the deleted self-close path
- `.gzkit/rules/*.md` — any rule file referencing lite-lane self-close (per grep)
- `.claude/skills/**/SKILL.md`, `.claude/rules/**/*.md` — Claude vendor mirrors (regenerated by sync; not edited directly per `.gzkit/rules/skill-surface-sync.md`)
- `.github/skills/**/SKILL.md`, `.github/instructions/**/*.md` — Copilot vendor mirrors (regenerated by sync)
- `.agents/skills/**/SKILL.md` — Codex vendor mirrors (regenerated by sync)
- `tests/governance/test_skill_self_close_drift.py` — new test module asserting zero remaining references to the deleted self-close path across canon and mirror surfaces

## Denied Paths

- `AGENTS.md` and all directory `**/AGENTS.md` mirrors — doctrine surface owned by OBPI-0.0.36-01
- `src/gzkit/commands/adr_audit.py` — runtime gate is OBPI-0.0.36-02
- `src/gzkit/governance/trust_audits.py`, `src/gzkit/validate_pkg/**` — validator scope is OBPI-0.0.36-03
- `data/historical_self_close_waivers.json`, `src/gzkit/models/historical_waiver.py` — waiver list is OBPI-0.0.36-04
- New runtime dependencies; CI files; lockfiles
- Direct edits to vendor-mirror files (`.claude/`, `.github/`, `.agents/`) — sync is the only legitimate authoring path per skill-surface-sync rule

## Requirements (FAIL-CLOSED)

1. REQUIREMENT: Every skill file under `.gzkit/skills/**/SKILL.md` containing a reference to "self-clos", "Self-closeable", "self-close", "feature.*lite.*self", or related lite-lane self-close prose MUST be edited to remove the reference and reflect the universal-attestation rule from ADR-0.0.36.
2. REQUIREMENT: Every rule file under `.gzkit/rules/**/*.md` containing the same references MUST be edited identically.
3. REQUIREMENT: Every edited skill MUST bump its frontmatter `skill-version:` per the skill-surface-sync version-discipline table — this sweep is a "governance rule or procedure change" warranting a minor bump.
4. REQUIREMENT: Every edited rule MUST bump its body-level `<!-- rule-version: X.Y.Z -->` HTML comment AND update the visible `> **Rule version:** \`X.Y.Z\`` block quote per `.gzkit/rules/skill-surface-sync.md` v0.2.0 rule-marker convention.
5. REQUIREMENT: After all canon edits, `uv run gz agent sync control-surfaces` MUST be run, and `git diff --stat` MUST show coordinated edits across canon (`.gzkit/`) and mirror (`.claude/`, `.github/`, `.agents/`) surfaces. A canon edit without mirror propagation is a partial-sync failure.
6. REQUIREMENT: `tests/governance/test_skill_self_close_drift.py` MUST assert that grep for the deleted patterns across `.gzkit/skills/**`, `.gzkit/rules/**`, `.claude/skills/**`, `.claude/rules/**`, `.github/skills/**`, `.github/instructions/**`, and `.agents/skills/**` returns zero matches outside an explicit allow-list (the historical-rationale section in this OBPI brief itself, ADR-0.0.36's own narrative, the GHI #332 audit doc).
7. REQUIREMENT: `ghi-close` v2.3.0's "NEVER, EVER, EVER dead-letter" doctrine MUST be cross-referenced in `gz-obpi-pipeline` and `gz-adr-closeout-ceremony` where those skills discuss closure flow — this sweep is the opportunity to land the cross-reference, since both skills' next prose pass intersects with universal-attestation.

> STOP-on-BLOCKERS: if `gz agent sync control-surfaces` fails or reports stale mirror-only paths, halt and follow `/gz-agent-sync` skill recovery before continuing.
