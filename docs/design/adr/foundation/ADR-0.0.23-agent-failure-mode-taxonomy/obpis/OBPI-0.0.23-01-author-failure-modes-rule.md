## Objective

Create the canonical rule file enumerating the six-pattern agent-failure-mode taxonomy, with each pattern carrying a definition, an external citation, and a pointer to the gzkit invariant that backstops it.

## Lane

**Lite** — This OBPI is rule/doctrine authoring, not a CLI/schema/runtime contract change. Foundation-kind triggers brief-level Gate 5 attestation regardless of lane (per § Lane & Kind Attestation Matrix).

## Requirements (FAIL-CLOSED)

1. REQUIREMENT: `.gzkit/rules/agent-failure-modes.md` exists with frontmatter `paths:` field scoped to the directories where authoring discipline applies (`AGENTS.md`, `.gzkit/rules/**`, `docs/governance/**`).
2. REQUIREMENT: The rule enumerates exactly six patterns, in this order: `Safeguard circumvention`, `Reckless action`, `Fabrication`, `Skipped cheap verification`, `Correction fails`, `Dishonest when caught`.
3. REQUIREMENT: Each pattern carries (a) a one-sentence definition, (b) an external citation with section anchor (Opus 4.7 § 2.3.6 or GPT-5.5 § 9.2), and (c) a pointer to the gzkit invariant that backstops it (one of: AGENTS.md § DO IT RIGHT 6a/6c/6g/6h, ARB receipts, `validate --commit-trailers`, T1/T2/T3 invariants).
4. REQUIREMENT: The rule includes a § "When to invoke this vocabulary" section with worked examples of how reviewers use the names ("this PR is `Skipped cheap verification` shape").
5. REQUIREMENT: The rule loads as advisory (no mechanical enforcement in this OBPI). Promotion to mechanical, where applicable, lands under follow-up GHIs (#308–#312).
6. REQUIREMENT: NEVER include the operator's personal email in the rule body or any example.
7. REQUIREMENT: Does NOT modify any rule file other than the new one.
8. REQUIREMENT: Does NOT update vendor mirrors (OBPI-03 handles sync).

> STOP-on-BLOCKERS: if `.gzkit/rules/` does not exist or the parent ADR file is absent, print BLOCKERS and halt.
