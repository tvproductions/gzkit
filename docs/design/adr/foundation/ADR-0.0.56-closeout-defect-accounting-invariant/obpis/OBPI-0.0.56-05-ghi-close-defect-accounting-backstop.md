## Requirements (FAIL-CLOSED)

<!-- Constraints that MUST hold. Numbered list. NEVER/ALWAYS language.
     These are the rules agents ground against. If not met, OBPI fails. -->

1. REQUIREMENT: A new PreToolUse hook MUST be added at `.claude/hooks/ghi-close-defect-accounting.py` (sibling shape: `.claude/hooks/ghi-triage-chat-silence.py`) that intercepts the `gh issue close` Bash action and runs the closeout-defect-accounting reconcile predicate. The hook filename is pinned: `ghi-close-defect-accounting.py`. When a gate-surfaced defect from the session lacks a routing receipt, the hook MUST block the close action (PreToolUse deny).
2. REQUIREMENT: The hook MUST be registered in `.claude/settings.json` under the `PreToolUse` `Bash` matcher block. An unregistered hook is inert — registration is part of the deliverable.
3. REQUIREMENT: The hook MUST REUSE the OBPI-02 reconcile predicate and OBPI-03 `RoutingReceipt` model — it is an adapter behind the same port. NEVER reimplement the fingerprint algorithm or the reconcile logic inside the hook (parent ADR § Port-vs-adapter framing).
4. REQUIREMENT: `.claude/hooks/` is a `.claude/`-only vendor surface with NO canonical `.gzkit/hooks/` source — the hook file is authored directly under `.claude/hooks/` and is NOT propagated by `gz agent sync control-surfaces`. The implementer MUST NOT attempt to canonicalize the hook into `.gzkit/`.
5. REQUIREMENT: The `ghi-close` skill update MUST be made to the CANONICAL `.gzkit/skills/ghi-close/SKILL.md` first, per `.claude/rules/skill-surface-sync.md` non-negotiable rule #1; `skill-version` and `last_reviewed` MUST be bumped in the same edit; `uv run gz agent sync control-surfaces` then propagates to `.claude/skills/ghi-close/SKILL.md`. The mirror MUST NEVER be hand-edited.
6. REQUIREMENT: The `ghi-close` skill update MUST NAME the mechanical reconcile gate as the structural witness — it MUST NOT add another prose anti-rationalization table. GHI #514's evidence shows prose did not bind; the parent ADR § Scope boundary forbids more prose tables.
7. REQUIREMENT: This OBPI is the BACKSTOP for the non-`gz` ghi-close surface ONLY. The hook is the secondary defense; it MUST NOT replace the `gz`-runtime mechanism (OBPI-01/02/03) — that mechanism remains primary (parent ADR § Alternatives Considered #1).
8. REQUIREMENT: Work MUST stay inside the Allowed Paths; NEVER include the operator's personal email in the hook, skill, or any example.

> STOP-on-BLOCKERS: if OBPI-02 (reconcile scope) / OBPI-03 (`RoutingReceipt`) are not yet landed, or `.claude/settings.json` / `.gzkit/skills/ghi-close/SKILL.md` is absent, print a BLOCKERS list and halt.
