## Objective

Author the `gz-owasp-scan` synthesizer skill at `.gzkit/skills/gz-owasp-scan/SKILL.md`. The skill wields the OBPI-02 chore + OBPI-03 CLI verb, layers judgment-shaped review on top of the mechanical floor for the categories the chore explicitly refuses to grade (A06 Insecure Design, A01 Broken Access Control, the judgment portions of A02 Security Misconfig and A08 Software/Data Integrity), and routes findings per the ADR's Routing rules table (Critical/High → GHI via `gz issue file`; Medium → in-flight fix or chore; Low/Info → report-only). The brief also lands the skill-trigger tests and the control-surface mirror sync via `gz agent sync control-surfaces`.

## Lane

**Heavy** — adds a new control-surface skill that mirrors into `.claude/skills/`, `.agents/skills/`, `.github/skills/`. Skill content + frontmatter are operator-facing contract surfaces.

> surface for security findings — its `gz_command:` frontmatter and
