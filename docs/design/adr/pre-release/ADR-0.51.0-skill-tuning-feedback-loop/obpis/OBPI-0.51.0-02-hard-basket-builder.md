## Requirements (FAIL-CLOSED)

<!-- Constraints that MUST hold. Numbered list. NEVER/ALWAYS language.
     These are the rules agents ground against. If not met, OBPI fails. -->

1. REQUIREMENT: `HardGoalBasket` MUST be a frozen Pydantic `BaseModel` with `extra="forbid"` exposing at minimum: `basket_id: str`, `skill_id: str`, `goals: tuple[HardGoal, ...]` with `Field(min_length=1)`, `source_evidence_refs: tuple[EvidenceRef, ...]` citing every signal source.
2. REQUIREMENT: The builder MUST consume all five signal sources named in ADR § Decision item 3: `.gzkit/insights/agent-insights.jsonl`, `skill_feedback` ledger events, OBPI pipeline friction (review GHI #424 round-3 hardening for shape), wrong-skill invocations, and ARB-backed command failures.
3. REQUIREMENT: The runner output MUST conform to the `SkillTuningEpisode.validation_results` field shape defined in OBPI-0.51.0-01 — schema/contract drift between builder/runner and episode model fail-closes the test suite.
4. REQUIREMENT: Canonical edits MUST go under `.gzkit/chores/...` first; `uv run gz agent sync control-surfaces` then propagates byte-equivalent copies to `src/gzkit/chores/...` (skill-surface-sync rule applies to chores via the canonical surface class-classifier).
5. NEVER: Mutate any `.gzkit/insights/agent-insights.jsonl` record from the builder — it is a read-only signal source.
6. NEVER: Emit narrative/prose justification in `HardGoalBasket` entries — structural-only shape consistent with `ghi-triage` round-3 hardening.
7. NEVER: Build a basket with empty `goals` tuple — `Field(min_length=1)` binding rejects degenerate baskets.
8. ALWAYS: Render any relative path in `source_evidence_refs` via `.as_posix()` per `.claude/rules/cross-platform.md`.

> STOP-on-BLOCKERS: if prerequisites are missing, print a BLOCKERS list and halt.
