## Requirements (FAIL-CLOSED)

<!-- Constraints that MUST hold. Numbered list. NEVER/ALWAYS language.
     These are the rules agents ground against. If not met, OBPI fails. -->

1. REQUIREMENT: The chore MUST expose exactly two run-modes named in ADR § Checklist item 4: `trim-and-verify` and `recalibrate-verify`; invocation MUST select the mode explicitly (no implicit default that could silently trim).
2. REQUIREMENT: `trim-and-verify` MUST: (a) propose a candidate trim of the target skill, (b) construct a hard basket (via OBPI-02 builder), (c) evaluate baseline AND candidate, (d) produce a `SkillTuningEpisode` (OBPI-01) with the comparative scores, (e) emit a report artifact under `.gzkit/chores/skill-tuning-optimize/proofs/<run-id>/`.
3. REQUIREMENT: `recalibrate-verify` MUST: (a) take no trim (same skill content), (b) construct a hard basket, (c) score against the current model, (d) emit a `SkillTuningEpisode` whose `candidate_skill_patch` field is the empty patch sentinel, (e) emit a report artifact.
4. REQUIREMENT: The chore MUST NOT be wired as a commit gate — it is an ad-hoc operator tool (ADR § Anti-pattern "Do not wire Optimize as a commit gate").
5. REQUIREMENT: The chore MUST emit a `skill_tuning` ledger event on completion of an accepted promotion decision — but `promotion_decision` MUST default to a non-accepted state and only become "accepted" with explicit operator gate (per ADR § Decision item 1 "qualitative feedback remains separate" + ADR § Alternatives Considered C).
6. REQUIREMENT: Report artifacts MUST live under `.gzkit/chores/skill-tuning-optimize/proofs/<run-id>/` per the chore-runner convention; the artifact MUST be a `SkillTuningEpisode` JSON serialization plus any trace_refs files.
7. NEVER: Auto-promote a skill — promotion remains human-reviewed (ADR § Alternatives Considered C); the chore writes report artifacts, never mutates `.gzkit/skills/**/SKILL.md` without explicit operator-attested promotion step.
8. NEVER: Run the chore as part of `uv run gz check` or any pre-commit pipeline — it is operator-invoked only.
9. ALWAYS: Cite the OBPI-01 episode contract and the OBPI-02 builder as the canonical inputs in the chore's CHORE.md body.

> STOP-on-BLOCKERS: if prerequisites are missing, print a BLOCKERS list and halt.
