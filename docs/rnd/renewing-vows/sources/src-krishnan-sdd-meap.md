## Scope (paraphrased)

A practical, tool-agnostic guide to spec-driven development for engineers who work with AI coding agents. Intent is made explicit in structured specifications, and those specifications, not the code, become the project's main control surface. A running URL-shortener example grows from single features to several repositories and teams. The book ties the practice to established fundamentals: extreme programming, refactoring legacy code, and managing technical debt. Topics include fixing defects through specifications, applying spec-driven development to brownfield code, autonomous iteration loops, and measuring specification quality.
