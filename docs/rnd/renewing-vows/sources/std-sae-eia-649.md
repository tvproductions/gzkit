## Scope (paraphrased)

The standard defines a set of configuration management (CM) functions and the principle behind each. Read together, the principles form a checklist for evaluating a CM program. They apply both to enterprise CM, meaning an organization's internal information, processes and systems, and to acquirer–supplier CM under contract. An acquirer can require a supplier CM plan consistent with the principles, use them to evaluate supplier plans, or write them into contract requirements.

The standard uses neutral CM terminology and neutral names for life cycle phases. All functions apply at every phase, scaled to the product's complexity, use and value. Implementation guidance is in GEIA-HB-649.

## Notes for the record

- The five CM functions named in SAE's public EIA649_1A scope are:
  1. configuration planning and management;
  2. configuration identification;
  3. configuration change management;
  4. configuration status accounting;
  5. configuration verification and audit.
