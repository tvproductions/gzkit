# Compression sweep: the 2026-09-17 control-surface rewrite

Dated record, 2026-09-24. Diagnostic only: this document changes no canon. It measures what meaning the 2026-09-17 compression of root `AGENTS.md`, `CLAUDE.md` and `governance-core.md` (GHI #921; commits `8ecb176f0`, `5adb751ee`, `fa1a52dca`) failed to carry forward, condition by condition. Figures here are a record of that measurement, not authority; re-derive them from git and `.gzkit/corpus/AGENTS.md.jsonl`.

## Why it was run

GHI #1090 found that the rewrite dropped the lane scope from the REQ-coverage gate rule, so `AGENTS.md` promised a universal fail-close the runtime does not perform. The operator ruled that compression must never lose meaning or intent, and asked whether #1090 was one slip or a pattern. It is a pattern. The permanent fix is ADR-0.35.0 checklist item 14 (OBPI-0.35.0-14, meaning-preserving landing).

## Method

A read-only agent took the baseline at `c3582975f` (the parent of `8ecb176f0`, `096e6bda3`, is identical for `AGENTS.md` and `CLAUDE.md`; `governance-core.md` differs only in its version header and one scope list). For each binding statement it split out the conditions (scope, qualifier, exception, threshold, named mechanism, cited authority) and located each one in the current surfaces. Verdicts: MOVED (present elsewhere), WEAKENED, BROADENED (now claims more than before), DROPPED. Only conditions that were not carried intact are listed. Severity `binding` means the finding changes what an agent may or must do; `context` means rationale or provenance only. Three findings (S01, S03, S04) were independently re-checked against git before this record was written.
