## Invariant

AGENTS.md MUST contain only (a) binding bullet rules (one bullet = one rule, ≤ 3 lines per bullet), (b) structured tables (Persona, Gate Covenant, OBPI kinds, canonical-invocations, defect-fix routing thresholds), and (c) canonical-link references to deeper documentation at stable URLs under `docs/governance/`. AGENTS.md MUST NOT contain (i) multi-paragraph rationale prose (paragraph > 5 lines without a binding-bullet anchor), (ii) worked examples or anti-pattern catalogs, (iii) "Why this is canon" / "Why X" coda blockquotes, (iv) narrative pedagogical sections, or (v) operative-claims expansions whose binding-bullet form already states the rule. CLAUDE.md inherits the same shape contract. `.claude/rules/*.md` files inherit the same shape with their existing 16k per-file budget.

## Five prohibited shapes

1. **Multi-paragraph rationale prose** — paragraph longer than 5 lines without a binding-bullet anchor. The rationale belongs in `docs/governance/`; the bullet states the rule.
2. **Worked examples or anti-pattern catalogs** — subsections titled "Worked example", "Anti-patterns", "Example", or equivalent. These belong in the canonical doctrine doc at a stable URL.
3. **"Why this is canon" / "Why X" coda blockquotes** — blockquote paragraphs that explain why a rule was chosen. These are encyclopedic; the bullet is the rule.
4. **Narrative pedagogical sections** — multi-paragraph explanations of how a rule works, its history, or its relationship to other rules. Route to `docs/governance/agent-contract-rationale.md`.
5. **Operative-claims expansions** — prose blocks restating operative claims whose binding-bullet form already states the rule fully. The binding bullet is sufficient; the expansion is accretion.

## Budget

The **live enforced budgets are the values in `data/instructions_files_budget.json`** — the single source of truth read by `gz validate --instructions-files-budget`. This doctrine never duplicates those numbers into prose: a duplicated number drifts from what is enforced (the exact drift ADR-0.0.54 closeout corrected). Read the JSON for the current enforced values.

The **destination** this doctrine sets for AGENTS.md is a tightened `15000`-char ceiling (the map, not the encyclopedia). That weight-halving is **not yet in force**: AGENTS.md currently sits above `15000` under a relaxed interim budget, and reaching the target is **deferred to GHI #533 → `ADR-0.35.0-canon-entry-corpus-landing`** § Decision 3 — sections declare `corpus-owned` or `unowned`, the generator materializes owned sections from the corpus, and the unowned byte total is held in a **decrease-only ratchet**. The predecessor pointer to `ADR-0.0.37` is **retired**: that ADR is terminal (§ Terminal Disposition, 2026-07-18) and its registry-spine OBPIs were permanently withdrawn, so no weight-halving work can land under it.

The transitional window is **open but no longer slack**. The delivered-surface witness (GHI #712, `src/gzkit/governance/trust_audits/surface_delivery_witness.py`) is wired into the default `gz check` scope, and AGENTS.md sits **560 B** under the Codex `project_doc_max_bytes` default — growth past that boundary fails the default gate closed. Shape enforcement (`gz validate --agents-md-map-conformance`) ships and binds now; the weight target lands with the deferred work. (ADR-0.0.54 closed Completed-Partial on exactly this split.)

## Shape enforcement

`gz validate --agents-md-map-conformance` (OBPI-0.0.54-03, forthcoming) asserts:
- No paragraph in AGENTS.md is > 5 lines without a binding-bullet anchor
- No subsection title is in the prohibited set
- Every `See [text](path)` link resolves to an existing file
- File size is measured against the budget in `data/instructions_files_budget.json` and reported — **advisory, never blocking** (operator ruling 2026-08-17; the earlier "until 1.0" wording is retired, see the version note). The same posture binds `gz validate --instructions-files-budget`. The three criteria above stay fail-closed — the stay is scoped to budget limits, never to shape.
- Bringing an over-budget surface back into trim is the `instructions-files-diet` chore's job, on a cadence or on demand — **not** an ordinary session's. Ordinary sessions add to sources (`gz content remember`) and never resize a render surface.

Validator emits `RemediationPayload` with `recovery: /gz-context-diet` on any violation.
